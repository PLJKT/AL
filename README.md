# AL 战斗成长档案（Ultra Growth Report）

一个用「六边形战士」游戏化概念记录孩子成长的单页网站。奥特曼战斗风格，面向孩子阅读与激励，兼顾家长评估。GitHub Pages 部署，仅限家人查看。

> 隐私约定：页面与代码中一律使用代号 **AL**，不出现孩子真实姓名。

## 当前版本（v5 · 100 分制 + 孩子向排版）

- 全部评分采用 **100 分制**（六维每维满分 100，技能满分 100）
- 主视图重构为「孩子向 6 大模块」，家长详细内容收进底部折叠的进阶区
- 页面高度较上一版减半（约 4933px），信息分层：孩子先看大数字与灯牌，家长再看明细

### 目标标准（页面「我的目标」灯牌）

- 每科 **分数 ≥ 90** 且 **态度 A** = 达标（绿灯）
- 分数 80–89 或态度 B = 冲刺中（黄灯，含分数 ≥90 但态度 B 的「分数 OK、态度待回 A」）
- 分数 < 80 = 要加油（红灯）
- 当前 P3 第一学期：达标 5 科 / 冲刺 7 科 / 要加油 0 科

### 六维合成口径（数据源：成绩单分数 + 态度评级）

- **数学逻辑** = 数学 × 70% + 科学 × 30%
- **语言表达** = 英语 × 40% + 普通话 × 35% + 印尼语 × 25%
- **艺术审美** =（艺术 + 音乐）/ 2
- **体能运动** = 体育
- **社交协作** = 品格 × 40% + 公民 × 30% + 全球视野 × 30%
- **学习专注** = 态度（A=10 / B=8）× 70% + 数字素养 × 30%

## 页面结构（自上而下）

1. **Hero**：综合战斗力大数字 81.7/100 + 六边形战力 / 技能战力 / 目标达标三个 chip
2. **我的六边形能力**：ECharts 雷达图（满分 100），K / P1 / P2 / P3 四段切换 + 学期按钮，虚线 = 该年级起点，实线 = 当前；右下六边形战力大数字
3. **我的六大能力**：6 张大卡（图标 + 大分数 + 进度条 + 一句话点评，P3 最新值）
4. **我的技能**：3 张技能卡（等级、分数、已解锁绝招、下一关提示）
5. **我的目标**：12 科灯牌卡（数学/科学/英语/普通话/印尼语/体育/数字素养/艺术/音乐/品格/公民/全球视野），绿灯达标 / 黄灯冲刺 / 红灯加油 + 汇总 chips
6. **我的成长曲线**：ECharts 折线图，小学 9 节点，六维 6 条线
7. **战斗记录**：16 节点时间线（grid 三列：阶段 / 轴 / 一句话战报）
8. **家长进阶区（details 折叠）**：学科修炼路线 9 卡、素养与习惯 3 卡、老师的话（中英）、评分说明
9. **footer**：鼓励语 + 学年概览

## 技术栈与约束

- 单文件自包含 `index.html`：CSS 内联 `<style>`、JS 内联 `<script>`，无构建步骤
- ECharts 5.5.0 走 jsDelivr（`https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js`）
- 字体走自托管镜像 miaoda.feishu.cn（ZCOOL KuaiLe 展示 + Noto Sans SC 正文），带系统字体 fallback
- 图片为相对路径 `assets/hero.png`（900×1200）、`assets/badge.png`（1024×1024），只写在 `<img src>` / CSS `url()` 中
- 图标全部内联 SVG，不用 emoji
- 家长进阶区（`<details class="parenthub">`）默认收起，孩子主视图保持干净

## 更新指南（每学期新成绩单）

1. 新成绩单到达后，把分数与态度按「六维合成口径」折算成 6 个 0–100 的值
2. 在 `index.html` 的 `allTerms` 数组末尾追加一个新节点（`grade` 取 K/P1/P2/P3 对应年级，`label`/`title`/`time` 写明学期与学年）
3. 同步更新（按需）：
   - `timelineStories` 追加一句话战报
   - 「我的目标」12 张 goal-card 的分数/态度/点评（P3 部分，静态 HTML）
   - 额外技能等级：每完成一个年级，三项技能各 +1 级，同步技能卡分数与已解锁绝招
   - 家长进阶区「学科修炼路线」「老师的话」「评分说明」如有新评语
4. 在 `AL/` 目录执行 `git add -A; git commit -m "..." ; git push`
5. 家人访问 https://pljkt.github.io/AL/ 查看（如未更新，Ctrl+F5 清缓存）
