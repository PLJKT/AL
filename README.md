# AL 的成长星图

一个用"六边形战士"概念记录孩子成长的互动网站。

## 这是什么

这是 AL 的个人成长档案，用六个维度（数学逻辑、语言表达、艺术审美、体能运动、社交协作、学习专注）的雷达图，可视化他从 2023 春到 2024 冬共七个学期的成长轨迹。

- 交互式雷达图：点击切换不同学期，对比起点和当前
- 六维成长故事：每个维度都有基于真实评语的成长叙事
- 成长时间线：七个学期的关键里程碑
- 闪光点墙：AL 最突出的天赋和进步

## 怎么用

直接打开 `index.html` 即可，无需服务器。也可以启用 GitHub Pages 让家人通过链接访问。

## 更新记录

每学期新成绩单出来后，更新 `index.html` 中的 `terms` 数组数据即可。
